# v1.0-icon — 앱 아이콘·브랜딩

**날짜:** 2026-06-09
**상태:** 디자인 승인됨 — spec 리뷰 대기
**선행:** v1.0-about까지 master merged. (v1.0 출시 준비 sub-project 3)

## Goal

출시에 필요한 앱 브랜딩을 갖춘다: (1) 어댑티브 런처 아이콘(현재 없음 → 시스템 기본 사용 중인 출시 블로커 해소), (2) 알림용 모노크롬 아이콘, (3) Android 12+ 스플래시. **콘셉트 B = 스파크(AI 반짝임)**, 브랜드색 `#1E5FBF`. 전부 벡터(XML) — 이미지 툴 불필요. minSdk 31이라 레거시 PNG mipmap 불필요(어댑티브만).

## Scope / 비목표
- 범위: 어댑티브 런처 아이콘(벡터 foreground + 브랜드 배경), manifest 아이콘 지정, 알림 스파크 아이콘(브리핑 교체), 스플래시(테마).
- 비목표: Play 스토어 512×512/피처 그래픽(스토어 메타데이터 sub-project), 레거시 PNG, 라이트/다크 아이콘 변형, 애니메이션 스플래시, 알람 알림 아이콘 변경(기존 시계 유지).

## Background
- `app`에 mipmap/ic_launcher **없음**, manifest `<application>`에 `android:icon` **없음** → 런처에서 시스템 기본 아이콘. 출시 블로커.
- 알림 벡터는 `:local`에 `ic_alarm_notification`(시계)·`ic_snooze`·`ic_check` 존재. **브리핑 알림(`BriefingNotifier`, :app)은 `android.R.drawable.ic_dialog_info`(프레임워크)** 사용 → 교체 대상.
- `themes.xml`: `Theme.Assistant`(parent `android:Theme.Material.Light.NoActionBar`), 스플래시 미설정.
- 브랜드색 `PRIMARY_500 = #1E5FBF`(ColorSet).

## Architecture / 구성

| 파일 | 역할 |
|---|---|
| `app/src/main/res/drawable/ic_launcher_foreground.xml` | 흰색 스파크 벡터(108dp 뷰포트, 중앙 안전영역 내) — 어댑티브 foreground |
| `app/src/main/res/values/ic_launcher_colors.xml` | `ic_launcher_background` = `#1E5FBF` |
| `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` | `<adaptive-icon>` background=색, foreground=벡터 |
| `app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml` | 동일(원형 마스크) |
| `app/src/main/AndroidManifest.xml` | `<application>`에 `android:icon="@mipmap/ic_launcher"` `android:roundIcon="@mipmap/ic_launcher_round"` |
| `app/src/main/res/drawable/ic_notification.xml` | 흰색 스파크 모노크롬(상태바용, 24dp) |
| `app/.../work/BriefingNotifier.kt` | `setSmallIcon(android.R.drawable.ic_dialog_info)` → `R.drawable.ic_notification`(app) |
| `app/src/main/res/values/themes.xml` | `Theme.Assistant`에 스플래시 속성(배경=브랜드색, 아이콘=스파크) |

`:app`만 변경(아이콘·테마·BriefingNotifier 모두 :app). 새 의존성·권한 없음.

## Components

### 스파크 벡터(foreground / notification)
4-point 스파크(오목 별) 흰색. foreground는 108×108 뷰포트(어댑티브 규격), 글리프는 중앙 ~안전영역(약 지름 60dp) 안. 알림용은 24×24 동일 형태(흰색, 상태바는 알파만 사용하므로 흰색 단색). 정확한 pathData는 plan에 수록.

### 어댑티브 아이콘
```xml
<!-- mipmap-anydpi-v26/ic_launcher.xml -->
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```
`ic_launcher_round.xml` 동일. (monochrome 슬롯=테마드 아이콘은 비범위.)

### manifest
`<application ... android:icon="@mipmap/ic_launcher" android:roundIcon="@mipmap/ic_launcher_round" ...>` (기존 속성 유지하며 추가).

### 스플래시(Android 12+)
`Theme.Assistant`에 추가:
```xml
<item name="android:windowSplashScreenBackground">@color/ic_launcher_background</item>
<item name="android:windowSplashScreenAnimatedIcon">@drawable/ic_launcher_foreground</item>
```
별도 라이브러리 없이 플랫폼 스플래시 사용(minSdk 31). 아이콘=흰 스파크 on 브랜드 배경.

### 알림 아이콘 교체
`BriefingNotifier`의 small icon을 `ic_notification`으로. (AlarmReceiver는 기존 `ic_alarm_notification` 유지.)

## Data Flow
정적 리소스. 런처/스플래시는 OS가 처리. 알림은 빌더가 `ic_notification` 참조.

## Error handling
정적 — 런타임 경로 없음. 아이콘 누락 시 빌드 실패로 조기 발견.

## Testing
- `./gradlew :app:assembleDebug` — 어댑티브 아이콘·매니페스트 병합·테마 컴파일 검증.
- (선택) `:app:lintDebug` — 아이콘/매니페스트 경고 0.
- 단위 테스트: BriefingNotifier 아이콘 참조 1줄 변경 — 로직 무관, 기존 테스트 무영향(`:app:testDebugUnitTest` PASS).
- 수동 smoke: 런처 새 아이콘(둥근사각·원형), 앱 시작 스플래시(스파크), 브리핑 알림 스파크 아이콘.
