# v1.0-about — About·라이선스·프라이버시

**날짜:** 2026-06-09
**상태:** 디자인 승인됨 — spec 리뷰 대기
**선행:** v1.0-i18n까지 master merged. (v1.0 출시 준비 sub-project 2)

## Goal

출시 필수인 (1) 앱 정보·버전, (2) OSS 라이선스 표기, (3) 프라이버시 정책을 **About 화면**으로 제공한다. `feature_settings`에 추가. Play 정책·법적(Apache-2.0 attribution, Gemma 라이선스) 요건 충족.

## Scope / 비목표
- 범위: feature_settings 내부에 About 화면(버전 + 라이선스 + 프라이버시), Settings에서 진입. 한·영.
- 비목표: 라이브러리별 개별 라이선스 전문(공통 Apache-2.0 전문 1회로 갈음), 외부 정책 URL/스토어 메타데이터(별도 sub-project), 동적 라이선스 자동생성, 변경로그/문의/평가 링크.

## Background
- `feature_settings`는 현재 `SettingsScene`=단일 `SettingsScreen`(브리핑 토글). 내부 네비 없음.
- `BuildConfig` 활성(`buildConfig = true`), `versionName = "0.1.0"` (단, BuildConfig는 :app에 생성됨 — 라이브러리 모듈 feature_settings의 BuildConfig는 자체 버전 없음). → **버전 문자열은 :app에서 주입하거나, feature_settings가 자체 BuildConfig.VERSION_NAME 없이 받는 구조 필요**(아래 Architecture).
- 출시 포함 의존성 전수(확인): AndroidX(core/appcompat/activity-compose/lifecycle/compose/navigation3/datastore/work/hilt-work), Jetpack Compose, Hilt·Dagger, Coil, Room, kotlinx(coroutines/serialization), OkHttp, Retrofit, LiteRT-LM — **전부 Apache-2.0**.
- **Gemma 4 모델 가중치는 Apache-2.0이 아니라 "Gemma Terms of Use"**(Google) — 별도 표기 + 약관 링크 필요. (LiteRT-LM SDK는 Apache-2.0, 모델은 Gemma 약관.)

## Architecture
`feature_settings`를 내부 네비게이션화([[feedback-scene-pattern]]): `SettingsScene`이 `NavDisplay`로 **Settings(목록) ↔ About** 서브라우트를 호스팅. `:app` 라우트 변경 없음(SettingsScene 단일 entry 유지).

| 요소 | 내용 |
|---|---|
| `feature_settings/build.gradle.kts` | navigation3(runtime/ui) + lifecycle-viewmodel-navigation3 + kotlin-serialization 추가(내부 NavDisplay·@Serializable 서브라우트용). 패턴은 `feature_memo` |
| `SettingsScene` | `NavDisplay(SettingsSubRoute.List ↔ SettingsSubRoute.About)`. `SettingsScreen`에 "앱 정보" row → About |
| `SettingsScreen` | 브리핑 토글 + "앱 정보" row(onClick → About) |
| `AboutScreen` | 버전 + OSS 라이선스(목록 + Apache-2.0 전문) + Gemma 모델 약관 + 프라이버시 정책. `Column` 스크롤 |
| 버전 주입 | `AboutScreen`에 `appVersion: String` 파라미터 → `SettingsScene(onBack, appVersion)` → `:app`이 `BuildConfig.VERSION_NAME` 전달. (라이브러리 모듈에서 :app BuildConfig 직접 못 읽으므로 주입.) |
| strings | About 신규 문자열 한·영(values/values-en). Apache-2.0 전문은 영문 표준 텍스트(번역 안 함) |

새 의존성: navigation3/serialization(이미 카탈로그). 권한 없음.

## Components

### `SettingsScene` (내부 NavDisplay)
```kotlin
@Composable
fun SettingsScene(onBack: () -> Unit, appVersion: String) {
    val backStack = rememberNavBackStack(SettingsSubRoute.List)
    NavDisplay(backStack = backStack, entryProvider = entryProvider {
        entry<SettingsSubRoute.List> {
            SettingsScreen(onBack = onBack, onOpenAbout = { backStack.add(SettingsSubRoute.About) })
        }
        entry<SettingsSubRoute.About> {
            AboutScreen(appVersion = appVersion, onBack = { backStack.removeLastOrNull() })
        }
    })
}
```
`SettingsSubRoute`(sealed, `@Serializable data object List/About`), `feature_memo`의 `MemoSubRoute` 패턴.

### `SettingsScreen`
기존 브리핑 토글 아래 "앱 정보(About)" row 추가 → `onOpenAbout`. `onBack` 파라미터 추가(상단바 뒤로 또는 기존 동작).

### `AboutScreen`
스크롤 Column:
1. 앱 이름 + `appVersion`(예: "버전 0.1.0" / "Version 0.1.0").
2. **오픈소스 라이선스** 섹션: 라이브러리명 목록(아래) + "다음 라이브러리는 Apache License 2.0 하에 배포됩니다" 안내 + Apache-2.0 전문(영문). 목록: AndroidX/Jetpack Compose, Hilt (Dagger), Kotlin Coroutines·Serialization (JetBrains), Coil, Room, OkHttp, Retrofit, AndroidX Navigation3/Lifecycle/DataStore/WorkManager, Google AI Edge LiteRT-LM.
3. **AI 모델** 섹션: "Gemma 4 (E2B) — Google. Gemma Terms of Use 적용." + 약관 URL 텍스트(https://ai.google.dev/gemma/terms). (클릭 가능 링크 또는 표시.)
4. **프라이버시 정책** 섹션: 온디바이스 핵심 문구(아래).

### 프라이버시 정책 문구(요지 — plan에서 한·영 전문)
- 모든 입력(텍스트·이미지·음성)·메모·일정은 **기기 내에서만** 처리·저장되며 서버로 전송되지 않음.
- 음성 인식은 시스템 STT 사용(시스템 정책 적용). 모델 파일은 최초 1회 HuggingFace에서 다운로드(입력 데이터 전송 아님).
- 권한 사용: 카메라(사진 캡처), 마이크(음성 입력), 캘린더(일정 등록), 알림(알람·브리핑), 정확한 알람.
- 데이터 삭제: 앱 삭제 시 모든 로컬 데이터 제거.

### i18n
About 신규 string 모두 values(한)·values-en(영). Apache-2.0 전문 string은 영문 한 벌(양 로케일 동일 참조 OK — 값 동일하게 두거나 values에만 두고 fallback). **plan에서 values/values-en에 동일 영문 전문 배치**(name parity 유지).

## Data Flow
정적 표시. Settings → "앱 정보" → AboutScreen(주입된 appVersion + 정적 strings). 외부 통신 없음. Gemma 약관 링크 탭 시 브라우저(Intent.ACTION_VIEW) — 선택(없으면 텍스트만).

## Error handling
정적 콘텐츠 — 런타임 에러 경로 없음. 약관 링크 Intent에 핸들러 없으면 무시(try/catch). 긴 텍스트 스크롤.

## Testing
