# v0.3.E — 음성 캡처 (STT) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 시스템 음성인식(STT)으로 발화를 텍스트로 변환해 기존 텍스트 분류 경로에 흘려보낸다. AI/모델 무변경.

**Architecture:** `CaptureScreen`에 음성 버튼 추가 → `RecognizerIntent.ACTION_RECOGNIZE_SPEECH`(EXTRA_PREFER_OFFLINE) 실행 → transcript를 입력 필드에 추가(`onInputChanged`) → 기존 "준비"로 분류. 권한·DB·usecase·ai 무변경.

**Tech Stack:** Android `RecognizerIntent`, Jetpack Compose ActivityResult.

**선행:** v0.3.A~D merged. spec: `docs/superpowers/specs/2026-06-05-v0.3e-audio-capture-design.md`. 브랜치 `feature/v0.3e-plan`.

> **이력:** 원래 Gemma audio 직접 분류로 시도했으나 모델 audio 미지원(spike 확인) → STT로 선회. audio 오버로드 코드는 revert 완료(master 복귀).

import 추가(없는 것만):
```kotlin

```
(`Intent`/`Toast`/`ActivityResultContracts`/`rememberLauncherForActivityResult`/`LocalContext` 일부는 v0.3.D에서 이미 import됨 — 중복 추가 금지, 확인 후 누락만.)

`CaptureScreen` 본문에서 `state`/`context`가 이미 정의된 위치(`val context = ... LocalContext.current`) 아래에 음성 런처 추가:
```kotlin
    val voiceUnavailable = stringResource(R.string.capture_voice_unavailable)
    val voicePrompt = stringResource(R.string.capture_voice_prompt)
    val speechLauncher =
        rememberLauncherForActivityResult(ActivityResultContracts.StartActivityForResult()) { result ->
            val transcript =
                result.data
                    ?.getStringArrayListExtra(RecognizerIntent.EXTRA_RESULTS)
                    ?.firstOrNull()
                    ?.trim()
            if (!transcript.isNullOrEmpty()) {
                val current = state.input.trim()
                viewModel.onInputChanged(if (current.isEmpty()) transcript else "$current $transcript")
            }
        }
```

이미지 소스 Row(갤러리/카메라 버튼이 있는 `Row`)에 세 번째 버튼 추가:
```kotlin
                    Button(onClick = {
                        val intent =
                            Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH).apply {
                                putExtra(
                                    RecognizerIntent.EXTRA_LANGUAGE_MODEL,
                                    RecognizerIntent.LANGUAGE_MODEL_FREE_FORM,
                                )
                                putExtra(RecognizerIntent.EXTRA_PREFER_OFFLINE, true)
                                putExtra(RecognizerIntent.EXTRA_LANGUAGE, java.util.Locale.getDefault())
                                putExtra(RecognizerIntent.EXTRA_PROMPT, voicePrompt)
                            }
                        try {
                            speechLauncher.launch(intent)
                        } catch (e: android.content.ActivityNotFoundException) {
                            Toast.makeText(context, voiceUnavailable, Toast.LENGTH_SHORT).show()
                        }
                    }) { Text(stringResource(R.string.capture_voice_input)) }
```

> 갤러리/카메라/음성 3버튼이 한 Row에 좁으면 줄바꿈 허용(별도 Row 또는 FlowRow). 기능 우선.
