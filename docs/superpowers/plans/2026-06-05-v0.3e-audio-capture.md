# v0.3.E — 음성(오디오) 캡처 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 앱에서 마이크로 녹음한 음성을 Gemma audio로 직접 분류(MEMO/EVENT/REMINDER)한다. 녹음은 분류용 일회성(저장 안 함).

**Architecture:** `InferenceEngine.generate`를 `generate(prompt, images, audio)` 단일 추상 + default 오버로드로 확장(텍스트/이미지 경로 무영향). `InferenceConfig.enableAudio` → `EngineConfig.audioBackend`. `AudioRecorder`(16kHz mono PCM16 → WAV 바이트) → `ClassifyAudioCaptureUseCase`(enableAudio 로드) → CaptureScreen 마이크 버튼. DB/메모 화면 변경 없음.

**Tech Stack:** Kotlin, LiteRT-LM 0.12.0 (`Content.AudioBytes`, `EngineConfig.audioBackend`), Android `AudioRecord`, Hilt, Compose, Robolectric/AndroidJUnit4.

**선행:** v0.3.A~D (PR #6/#7/#8/#9) 모두 master merged. spec: `docs/superpowers/specs/2026-06-05-v0.3e-audio-capture-design.md`. 브랜치 `feature/v0.3e-plan`.

**⚠️ GATING:** Task 2(spike)가 실패하면 Task 3 이후를 중단하고 사용자에게 보고(audio 미지원 → STT 폴백/보류 결정). Task 1·2 먼저 완료해 audio 실동작 + 바이트 형식을 확정한 뒤 본 구현.

```kotlin
        override suspend fun generate(
            prompt: String,
            images: List<ByteArray>,
            audio: List<ByteArray>,
        ): String =
            withContext(Dispatchers.IO) {
                val e = engine ?: error("InferenceEngine not loaded; call load() first")
                val cfg = currentConfig ?: error("InferenceEngine not loaded; call load() first")

                val samplerConfig =
                    SamplerConfig(
                        topK = cfg.topK,
                        topP = cfg.topP.toDouble(),
                        temperature = cfg.temperature.toDouble(),
                        seed = 0,
                    )
                val conversationConfig =
                    ConversationConfig(
                        systemInstruction = null,
                        initialMessages = emptyList(),
                        tools = emptyList(),
                        samplerConfig = samplerConfig,
                    )

                e.createConversation(conversationConfig).use { conversation ->
                    val response =
                        if (images.isEmpty() && audio.isEmpty()) {
                            conversation.sendMessage(prompt)
                        } else {
                            val parts =
                                images.map { Content.ImageBytes(it) } +
                                    audio.map { Content.AudioBytes(it) } +
                                    Content.Text(prompt)
                            conversation.sendMessage(Contents.of(parts))
                        }
                    response.contents.contents
                        .filterIsInstance<Content.Text>()
                        .joinToString(separator = "") { it.text }
                }
            }
```

```kotlin
package com.just.assistant.regression

import android.util.Log
import androidx.test.core.app.ApplicationProvider
import androidx.test.ext.junit.runners.AndroidJUnit4
import com.just.assistant.ai.inference.InferenceConfig
import com.just.assistant.ai.inference.LiteRtLmInferenceEngine
import kotlinx.coroutines.runBlocking
import org.junit.Assert.assertTrue
import org.junit.Assume.assumeTrue
import org.junit.Test
import org.junit.runner.RunWith
import java.io.File

/**
 * GATING spike: 현재 .litertlm 모델이 audio 입력을 실제로 추론하는지 + Content.AudioBytes가
 * 받는 바이트 형식(우선 WAV 파일 바이트)을 확인.
 * 통과 = 예외 없음 + 응답이 발화 토큰 반영.
 */
@RunWith(AndroidJUnit4::class)
class AudioInferenceSpikeTest {
    @Test
    fun model_transcribes_audio() =
        runBlocking {
            val context = ApplicationProvider.getApplicationContext<android.content.Context>()
            val modelsDir = File(context.filesDir, "models")
            val modelFile = modelsDir.listFiles()?.firstOrNull { it.name.endsWith(".litertlm") }
            assumeTrue("No .litertlm model — adb push 필요", modelFile != null)

            val wavBytes = context.assets.open("spike/voice_16k_mono.wav").readBytes()

            val engine = LiteRtLmInferenceEngine(context)
            engine.load(modelFile!!, InferenceConfig(enableAudio = true, preferGpu = false))
            val response =
                try {
                    engine.generate(
                        prompt = "이 음성에서 들리는 말을 그대로 적어주세요.",
                        images = emptyList(),
                        audio = listOf(wavBytes),
                    )
                } finally {
                    engine.unload()
                }

            Log.i("Spike", "audio response = $response")
            val tokens = listOf("회의", "강남", "세시", "3", "내일", "오후")
            assertTrue(
                "응답이 발화를 전혀 반영하지 않음 (audio 미지원 의심). response=$response",
                response.isNotEmpty() && tokens.any { response.contains(it) },
            )
        }
}
```

- [ ] **Step 3: AudioRecorder + pcm16ToWav 구현**

```kotlin
package com.just.assistant.local.audio

import android.annotation.SuppressLint
import android.media.AudioFormat
import android.media.AudioRecord
import android.media.MediaRecorder
import java.io.ByteArrayOutputStream
import javax.inject.Inject
import javax.inject.Singleton

interface AudioRecorder {
    fun start()
    /** 녹음 종료 후 분류용 오디오 바이트(16kHz mono WAV) 반환. */
    fun stop(): ByteArray
    fun isRecording(): Boolean
}

private const val SAMPLE_RATE = 16000

@Singleton
class AudioRecorderImpl
    @Inject
    constructor() : AudioRecorder {
        @Volatile private var record: AudioRecord? = null
        @Volatile private var thread: Thread? = null
        private val pcm = ByteArrayOutputStream()

        @SuppressLint("MissingPermission") // 호출 측(UI)에서 RECORD_AUDIO 권한 확보 후 호출
        override fun start() {
            if (record != null) return
            val minBuf =
                AudioRecord.getMinBufferSize(
                    SAMPLE_RATE,
                    AudioFormat.CHANNEL_IN_MONO,
                    AudioFormat.ENCODING_PCM_16BIT,
                )
            val bufSize = if (minBuf > 0) minBuf else SAMPLE_RATE * 2
            pcm.reset()
            val rec =
                AudioRecord(
                    MediaRecorder.AudioSource.MIC,
                    SAMPLE_RATE,
                    AudioFormat.CHANNEL_IN_MONO,
                    AudioFormat.ENCODING_PCM_16BIT,
                    bufSize,
                )
            record = rec
            rec.startRecording()
            thread =
                Thread {
                    val buf = ByteArray(bufSize)
                    while (record != null) {
                        val n = rec.read(buf, 0, buf.size)
                        if (n > 0) pcm.write(buf, 0, n)
                    }
                }.also { it.start() }
        }

        override fun stop(): ByteArray {
            val rec = record ?: return ByteArray(0)
            record = null
            thread?.join(500)
            thread = null
            rec.stop()
            rec.release()
            return pcm16ToWav(pcm.toByteArray(), SAMPLE_RATE, channels = 1)
        }

        override fun isRecording(): Boolean = record != null
    }

/** raw PCM16 LE 바이트에 44바이트 WAV 헤더를 붙여 WAV 바이트 반환. */
fun pcm16ToWav(pcm: ByteArray, sampleRate: Int, channels: Int): ByteArray {
    val byteRate = sampleRate * channels * 2
    val blockAlign = channels * 2
    val dataSize = pcm.size
    val totalSize = 36 + dataSize
    val header = ByteArrayOutputStream(44)
    fun writeStr(s: String) = header.write(s.toByteArray(Charsets.US_ASCII))
    fun writeIntLE(v: Int) {
        header.write(v and 0xFF)
        header.write((v shr 8) and 0xFF)
        header.write((v shr 16) and 0xFF)
        header.write((v shr 24) and 0xFF)
    }
    fun writeShortLE(v: Int) {
        header.write(v and 0xFF)
        header.write((v shr 8) and 0xFF)
    }
    writeStr("RIFF"); writeIntLE(totalSize); writeStr("WAVE")
    writeStr("fmt "); writeIntLE(16); writeShortLE(1); writeShortLE(channels)
    writeIntLE(sampleRate); writeIntLE(byteRate); writeShortLE(blockAlign); writeShortLE(16)
    writeStr("data"); writeIntLE(dataSize)
    return header.toByteArray() + pcm
}
```

```kotlin
package com.just.assistant.usecase.capture.impl

import com.just.assistant.ai.inference.InferenceConfig
import com.just.assistant.ai.inference.InferenceEngine
import com.just.assistant.ai.prompt.AudioClassificationPrompt
import com.just.assistant.ai.prompt.ClassificationResult
import com.just.assistant.local.model.ModelFileStore
import com.just.assistant.local.model.ModelStatusPrefs
import com.just.assistant.usecase.capture.di.ClassifyAudioCaptureUseCase
import kotlinx.coroutines.flow.first
import javax.inject.Inject

class ClassifyAudioCaptureUseCaseImpl
    @Inject
    constructor(
        private val engine: InferenceEngine,
        private val fileStore: ModelFileStore,
        private val prefs: ModelStatusPrefs,
    ) : ClassifyAudioCaptureUseCase {
        override suspend fun invoke(audioBytes: ByteArray): ClassificationResult? {
            val variantId = prefs.selectedVariantId.first() ?: return null
            val modelFile = fileStore.fileFor(variantId).takeIf { it.exists() } ?: return null
            return try {
                // enableAudio=true 로 로드. audioBackend 미초기화 시 정지(v0.3.D vision 교훈).
                // isReady() 가드 없이 매번 load (내부 dedup).
                engine.load(modelFile, InferenceConfig(enableAudio = true))
                val response =
                    engine.generate(
                        prompt = AudioClassificationPrompt.build(),
                        images = emptyList(),
                        audio = listOf(audioBytes),
                    )
                ClassificationResult.parse(response)
            } catch (t: Throwable) {
                null
            }
        }
    }
```
