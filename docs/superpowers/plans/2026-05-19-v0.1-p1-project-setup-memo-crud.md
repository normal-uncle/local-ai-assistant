## File Structure

### Scene 컨벤션 (중요)

본 프로젝트는 화면 단위를 두 계층으로 나눈다:

- **`Scene`** = feature 모듈의 **entry container** + 모듈 내부 navigation host.
  - `:app`은 오직 `Scene`만 알고, 그 내부 `Screen`을 모른다 (feature 캡슐화).
  - **multi-screen feature** → `Scene`이 `NavDisplay` + sub-route(`XxxSubRoute`)를 호스트하며 sub-route는 `Screen` 진입점에 매핑된다.
  - **single-screen feature** → `Scene`은 단일 `Screen`을 호출하는 얇은 wrapper.
- **`Screen`** = 실제 UI 단위. feature 모듈 내부에 살며, parent `Scene`을 통해서만 접근된다. 기본 `internal` 가시성.
- 사용자 노출 문자열은 모듈별 `res/values/strings.xml`에 둔다 (`<module>_*` 키 네임스페이스).

**컨벤션 메모 (imin 따름):**
- 모듈 이름: 콜론 평탄형 (`:feature_capture`, 디렉토리는 `feature_capture/`).
- 패키지: 메인 `com.just.assistant.*`, feature 모듈은 `com.just.feature.{name}.*`, ui_component는 `com.just.assistant.ui.component.*`.
- Composable 진입점 컨벤션: feature의 public entry는 `XxxScene` (네비게이션 컨테이너), 실제 UI는 `screen/XxxScreen` (internal). 위 "Scene 컨벤션" 섹션 참고.
- 사용자 노출 문자열은 Kotlin 리터럴 금지. 모듈별 `src/main/res/values/strings.xml`에 `<module>_*` 네임스페이스 키로 둔다.
- UseCase: `di/XxxUseCase` (인터페이스) + `impl/XxxUseCaseImpl`.
- Repository: `di/XxxRepository` (인터페이스) + `impl/XxxRepositoryImpl`.
- 모든 모듈 `jvmToolchain(18)`, `compileSdk { version = release(36) }`, `minSdk = 31` (spec에 정의된 NNAPI 안정·온디바이스 STT 기준).
- 테스트는 JUnit4 + `kotlinx-coroutines-test` (imin 컨벤션 — MockK/Turbine은 도입하지 않음, fake 객체는 테스트 파일 안에서 직접 정의).

```kotlin
package com.just.assistant.repository.impl

import com.just.assistant.local.note.NoteDao
import com.just.assistant.local.note.NoteEntity
import com.just.assistant.repository.di.NoteRepository
import com.just.assistant.usecase.entity.Note
import com.just.assistant.usecase.entity.NoteType
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.map
import java.time.Instant
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class NoteRepositoryImpl
    @Inject
    constructor(
        private val dao: NoteDao,
        private val clock: () -> Instant = { Instant.now() },
    ) : NoteRepository {
        override fun observeAll(): Flow<List<Note>> = dao.observeAll().map { list -> list.map { it.toDomain() } }

        override suspend fun findById(id: Long): Note? = dao.findById(id)?.toDomain()

        override suspend fun save(note: Note): Long {
            val now = clock()
            return if (note.id == 0L) {
                dao.insert(
                    note.toEntity().copy(
                        createdAtEpochMs = now.toEpochMilli(),
                        updatedAtEpochMs = now.toEpochMilli(),
                    ),
                )
            } else {
                dao.update(note.toEntity().copy(updatedAtEpochMs = now.toEpochMilli()))
                note.id
            }
        }

        override suspend fun delete(id: Long): Boolean = dao.deleteById(id) > 0

        private fun NoteEntity.toDomain(): Note =
            Note(
                id = id,
                title = title,
                body = body,
                type = runCatching { NoteType.valueOf(type) }.getOrDefault(NoteType.MEMO),
                tags = if (tags.isBlank()) emptyList() else tags.split(",").map { it.trim() },
                datetime = datetimeIso?.let(Instant::parse),
                createdAt = Instant.ofEpochMilli(createdAtEpochMs),
                updatedAt = Instant.ofEpochMilli(updatedAtEpochMs),
            )

        private fun Note.toEntity(): NoteEntity =
            NoteEntity(
                id = id,
                title = title,
                body = body,
                type = type.name,
                tags = tags.joinToString(","),
                datetimeIso = datetime?.toString(),
                createdAtEpochMs = createdAt.toEpochMilli(),
                updatedAtEpochMs = updatedAt.toEpochMilli(),
            )
    }
```

```kotlin
        var lastReturnedId: Long = 0L

        override suspend fun findById(id: Long): Note? = flow.value.firstOrNull { it.id == id }

        override suspend fun save(note: Note): Long {
            saved = note
            lastReturnedId = (flow.value.maxOfOrNull { it.id } ?: 0L) + 1
            val withId = note.copy(id = lastReturnedId)
            flow.update { it + withId }
            return lastReturnedId
        }

        override suspend fun delete(id: Long): Boolean {
            val removed = flow.value.any { it.id == id }
            flow.update { list -> list.filterNot { it.id == id } }
            return removed
        }
    }
```

```kotlin
package com.just.feature.capture.capture

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.just.assistant.repository.model.Note
import com.just.assistant.repository.model.NoteType
import com.just.assistant.usecase.note.di.SaveNoteUseCase
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch
import java.time.Instant
import javax.inject.Inject

data class CapturePreview(
    val title: String,
    val body: String,
    val type: NoteType,
    val tags: List<String> = emptyList(),
)

data class CaptureState(
    val input: String = "",
    val preview: CapturePreview? = null,
    val isSaving: Boolean = false,
    val error: String? = null,
)

@HiltViewModel
class CaptureViewModel
    @Inject
    constructor(
        private val saveNote: SaveNoteUseCase,
    ) : ViewModel() {
        private val _state = MutableStateFlow(CaptureState())
        val state: StateFlow<CaptureState> get() = _state.asStateFlow()

        fun onInputChanged(text: String) {
            _state.update { it.copy(input = text) }
        }

        fun onPrepare() {
            val input = _state.value.input.trim()
            if (input.isEmpty()) return
            val firstNewline = input.indexOf('\n')
            val title = if (firstNewline < 0) input else input.substring(0, firstNewline).trim()
            val body = if (firstNewline < 0) "" else input.substring(firstNewline + 1).trim()
            _state.update {
                it.copy(preview = CapturePreview(title = title, body = body, type = NoteType.MEMO))
            }
        }

        fun onCancel() {
            _state.update { it.copy(preview = null) }
        }

        fun onConfirm(edited: CapturePreview) {
            if (_state.value.preview == null) return
            if (_state.value.isSaving) return
            _state.update { it.copy(preview = edited, isSaving = true) }
            viewModelScope.launch {
                val now = Instant.now()
                try {
                    saveNote(
                        Note(
                            title = edited.title,
                            body = edited.body,
                            type = edited.type,
                            tags = edited.tags,
                            createdAt = now,
                            updatedAt = now,
                        ),
                    )
                    _state.update { CaptureState() }
                } catch (t: Throwable) {
                    _state.update { it.copy(isSaving = false, error = t.message ?: "저장 실패") }
                }
            }
        }
    }
```

```kotlin
package com.just.feature.memo

import androidx.compose.runtime.Composable
import androidx.navigation3.runtime.entryProvider
import androidx.navigation3.runtime.rememberNavBackStack
import androidx.navigation3.ui.NavDisplay
import com.just.feature.memo.memoDetail.MemoDetailScreen
import com.just.feature.memo.memoList.MemoListScreen

@Composable
fun MemoScene(onBackToApp: () -> Unit) {
    val backStack = rememberNavBackStack(MemoSubRoute.List)
    NavDisplay(
        backStack = backStack,
        entryProvider =
            entryProvider {
                entry<MemoSubRoute.List> {
                    MemoListScreen(
                        onOpenDetail = { id -> backStack.add(MemoSubRoute.Detail(id)) },
                        onBack = onBackToApp,
                    )
                }
                entry<MemoSubRoute.Detail> {
                    MemoDetailScreen(
                        onBack = { backStack.removeLastOrNull() },
                    )
                }
            },
    )
}
```

## 의도적 컨벤션 차이 (imin → 본 프로젝트)

다음은 imin과 다르게 가져간 결정과 이유:

| 항목 | imin | 본 프로젝트 | 이유 |
|---|---|---|---|
| Room | 미사용 (Retrofit + DataStore만) | 사용 — `:local` 안에 둠 | 로컬 메모 영속이 본 앱 도메인의 핵심 |
| DataStore Protobuf | 사용 | Preferences DataStore | P1 스코프에 protobuf serializer 도입은 과함. P2에서 모델 설정 복잡해지면 검토 |
| Product flavors | real / real_inner / dev_test | 미설정 | v0.1엔 단일 빌드. 출시 단계(v1.0)에서 dev/real 분리 |
| Firebase | Crashlytics + Analytics + Messaging | 미사용 | 온디바이스 비서라 분석·메시징 불필요. v1.0 출시 직전 Crashlytics만 도입 검토 |
| feature 모듈 패키지 | `kr.co.feature.{name}` 와 `kr.co.iminfintech.feature.{name}` 혼재 | `com.just.feature.{name}` 통일 | 일관성 |
| minSdk | 28 | 31 | spec 명시 — NNAPI 안정·온디바이스 SpeechRecognizer (Android 12+) 요구. P2에서 STT/온디바이스 추론 도입 시 필수 |

위 차이는 의도된 것이며, P2~v1.0 진행 중 필요하면 재검토.
