# v1.0-i18n — 다국어(한·영) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`).

**Goal:** 7개 모듈에 영어 리소스(`values-en/strings.xml`)를 추가해 앱 UI를 한·영 양쪽으로 표시한다(기본=한국어).

**Architecture:** 각 모듈 `src/main/res/values-en/strings.xml`에 `values/`와 동일한 string name을 영어로 채움 → Android가 기기 로케일로 자동 선택, 미존재 시 한국어 폴백. UI 하드코딩 한글 폴백 2곳을 string 리소스로. app에 `resourceConfigurations=["en","ko"]`.

**Tech Stack:** Android resource qualifiers (values-en), Gradle.

**선행:** v0.6 master. spec: `docs/superpowers/specs/2026-06-09-v1.0-i18n-design.md`. 브랜치 `feature/v1.0-i18n`.

**원칙:** string name·포맷 인자(`%1$d`, `%2$s`, `%%`)는 `values/`와 **완전히 동일**. 신규 string 2개는 `values/`(한국어)·`values-en/`(영어) 양쪽에 추가. 빌드 후 name 1:1 검증(Task 5).
