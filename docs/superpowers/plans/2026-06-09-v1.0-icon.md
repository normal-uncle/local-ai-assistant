# v1.0-icon — 앱 아이콘·브랜딩 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`).

**Goal:** 스파크(콘셉트 B) 어댑티브 런처 아이콘 + 알림 아이콘 + Android 12 스플래시를 추가한다(브랜드 #1E5FBF, 전부 벡터).

**Architecture:** `:app`에 어댑티브 아이콘(흰 스파크 벡터 foreground + 브랜드색 배경) + manifest 지정, 알림용 모노 스파크 벡터 + BriefingNotifier 교체, Theme.Assistant 스플래시 속성. minSdk 31 → 레거시 PNG 불필요.

**Tech Stack:** Android vector drawable, adaptive-icon, platform splash(API 31+).

**선행:** v1.0-about master. spec: `docs/superpowers/specs/2026-06-09-v1.0-icon-design.md`. 브랜치 `feature/v1.0-icon`.

**확인된 현황:** app에 mipmap/ic_launcher·manifest icon 없음. `themes.xml`=`<style name="Theme.Assistant" parent="android:Theme.Material.Light.NoActionBar" />`(self-closing). manifest `<application>`(name/allowBackup/label/supportsRtl/theme). `BriefingNotifier`(`com.just.assistant.work`) `setSmallIcon(android.R.drawable.ic_dialog_info)`.

```xml
    <path
        android:fillColor="#FFFFFF"
        android:pathData="M54,24 C57,45 63,51 84,54 C63,57 57,63 54,84 C51,63 45,57 24,54 C45,51 51,45 54,24 Z"/>
</vector>
```

- [ ] **Step 2: 배경색**

`app/src/main/res/values/ic_launcher_colors.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <color name="ic_launcher_background">#1E5FBF</color>
</resources>
```

- [ ] **Step 3: 어댑티브 아이콘 2개**

`app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```
`app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml`: 동일 내용(파일만 별도).

- [ ] **Step 4: manifest 아이콘 지정**

`AndroidManifest.xml`의 `<application>` 여는 태그에 `android:icon`/`android:roundIcon` 추가:
```xml
    <application
        android:name=".AssistantApplication"
        android:allowBackup="false"
        android:icon="@mipmap/ic_launcher"
        android:roundIcon="@mipmap/ic_launcher_round"
        android:label="@string/app_name"
        android:supportsRtl="true"
        android:theme="@style/Theme.Assistant">
```

- [ ] **Step 5: 빌드 확인**

Run: `./gradlew :app:assembleDebug`
Expected: BUILD SUCCESSFUL. (어댑티브 아이콘·매니페스트 병합 통과. minSdk 31이라 PNG 폴백 경고 없음.)
