# v1.0-release — 릴리스 빌드(R8 + 서명 골격) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `:app` release 빌드에 R8 코드/리소스 축소 + 안전한 keep 규칙 + keystore.properties 기반 서명 골격(부재 시 unsigned)을 적용한다. versionName 0.1.0 유지.

**Architecture:** `app/build.gradle.kts` 상단에서 루트 `keystore.properties`를 조건부 로드 → 프로퍼티가 있을 때만 `signingConfigs.release` 생성 → `buildTypes.release`에 `isMinifyEnabled`/`isShrinkResources`/(있으면)`signingConfig` 지정. 신설 `app/proguard-rules.pro`에 kotlinx-serialization·LiteRT-LM(JNI) keep 규칙. Hilt/Room/Compose/Retrofit/OkHttp는 자체 consumer 규칙으로 충분. 빌드 타임만 변경, 런타임 로직 무변경.

**Tech Stack:** Android Gradle Plugin(Kotlin DSL), R8(proguard-android-optimize), kotlinx-serialization, LiteRT-LM(JNI), `java.util.Properties`.

**선행:** v1.0-icon까지 master merged. spec: `docs/superpowers/specs/2026-06-09-v1.0-release-build-design.md`. 브랜치 `feature/v1.0-release`(spec 커밋 8ebe633 존재).

**확인된 현황(2026-06-09):**
- `app/build.gradle.kts:26-32` release block = `isMinifyEnabled = false`, `proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")` 참조하나 **`app/proguard-rules.pro` 파일 없음**.
- `.gitignore`에 `local.properties`/`*.keystore`/`*.jks` 존재. `keystore.properties` **미포함**.
- `@Serializable`: NavKey 라우트(`AssistantRoute`/`SettingsSubRoute`/`MemoSubRoute`), 원격 DTO(`CatalogDto`/`VariantDto`), ai(`ClassificationResult`/`ClassificationGoldenCase`) — 패키지 prefix 전부 `com.just.**`.

## Task 3: `app/build.gradle.kts` — keystore 로드 + 조건부 signingConfig + release R8 활성

**Files:**
- Modify: `app/build.gradle.kts`

`proguard-rules.pro`가 존재(Task 1)하고 ignore가 준비(Task 2)된 상태에서 release를 R8 활성으로 전환하고 서명 골격을 추가한다.

- [ ] **Step 1: 파일 상단 import + keystore.properties 로드 블록 추가**

`app/build.gradle.kts` 최상단(`plugins { ... }` 위)에 import 추가, `plugins`/`kotlin` 블록과 `android {` 사이에 로드 블록 추가. 구체적으로:

`plugins {` 위에:
```kotlin
import java.util.Properties
```

`kotlin { jvmToolchain(18) }` 다음 줄(빈 줄 후, `android {` 앞)에:
```kotlin
val keystoreProps = Properties().apply {
    val f = rootProject.file("keystore.properties")
    if (f.exists()) f.inputStream().use { load(it) }
}
```

- [ ] **Step 2: `android { }` 안에 signingConfigs(조건부) 추가**

`android {` 블록 안, `defaultConfig { ... }` 다음에 추가:
```kotlin
    signingConfigs {
        if (keystoreProps.getProperty("storeFile") != null) {
            create("release") {
                storeFile = file(keystoreProps.getProperty("storeFile"))
                storePassword = keystoreProps.getProperty("storePassword")
                keyAlias = keystoreProps.getProperty("keyAlias")
                keyPassword = keystoreProps.getProperty("keyPassword")
            }
        }
    }
```

- [ ] **Step 3: `buildTypes.release` R8 활성 + 조건부 signingConfig**

기존:
```kotlin
        release {
            isMinifyEnabled = false
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
        }
```
를:
```kotlin
        release {
            isMinifyEnabled = true
            isShrinkResources = true
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
            if (keystoreProps.getProperty("storeFile") != null) {
                signingConfig = signingConfigs.getByName("release")
            }
        }
```
로 변경.

- [ ] **Step 4: release 빌드 — R8 축소 + unsigned 패키징 성공 확인**

# 릴리스 서명 가이드

릴리스 APK/AAB에 서명하려면 루트에 `keystore.properties`(gitignored)를 만든다.
파일이 없으면 release 빌드는 **unsigned**로 성공한다(CI/시크릿 없는 환경 보호).

## 1. keystore 생성 (최초 1회)
```bash
keytool -genkeypair -v -keystore release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias assistant
```
> `release.jks`는 안전한 곳에 보관하고 **절대 커밋하지 않는다**(`*.jks` ignore됨). 분실 시 Play 업데이트 불가.

## 2. keystore.properties 작성 (루트)
```
storeFile=/absolute/path/to/release.jks
storePassword=****
keyAlias=assistant
keyPassword=****
```

## 3. 서명된 release 빌드
```bash
./gradlew :app:assembleRelease
```
